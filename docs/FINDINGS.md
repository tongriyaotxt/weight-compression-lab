## 1. 权重里有结构吗？—— 没有

五种独立检验、四个尺度，全部零假设：

| 假设 | 检验 | 实测 | 零假设 | 判定 |
|---|---|---|---|---|
| 语法 / 程序化权重（tile 自相似） | 32×32 码本 k=128 + 8 种二面体变换 | 51.19% 能量捕获 | 打乱后 **51.19%** | ❌ |
| 局部自相似 | 8×8 最近邻相关，抽样 1500 | 0.4383 | 随机 **0.4780** | ❌ |
| 近似重复神经元 | 2048 行两两相关 | 最大 0.343，>0.9 占 **0%** | — | ❌ |
| 生成式 / 低秩 | rank-256 SVD | 30.5% 能量 / 占 1.25% 参数 | 随机 6.25% | ❌ |
| 跨层差分（层剪枝的暗示） | 21 组张量对 corr | **\|corr\| < 0.001，节省为负** | — | ❌ |
| 码流自相关 | lag 1..64 | 全部 \|ac\| < 0.0017，均值 0.00053 | 噪声底 0.00069 | ❌ |
| 位置结构 | 按位置取模 2..128 的熵 | 完全平坦，max−min < 0.08 bit | — | ❌ |
| 逐层 bit 分配 | 反向注水（σ 跨 5.75×） | **+0.11 dB = 0.019 bit** | — | ❌ ≈0 |
| embed/lm_head 复用 | 整块哈希 + 线性 R² | 不是同一份 | — | ❌ 593 MB 不存在 |

> **结论：训练出来的 LLM 权重，信息含量等于它的边际分布，一分不多。**
> 量化噪声只把相关性衰减 `σ²/(σ²+D) = 0.98`，所以测到的 0.001 是真的。

## 2. 熵编码：22.1%，而且是零损失

| | 名义 | 熵 | 节省 |
|---|---:|---:|---:|
| i4 张量（6.946B 参数，252 个） | 3312.0 MiB | 2436.1 MiB | 26.4% |
| u8 张量（embed + lm_head，1.245B） | 1187.3 MiB | 1069.9 MiB | 9.9% |
| **合计** | **4499.3 MiB** | **3506.0 MiB** | **22.1%** |

编码器实测（16 符号，2¹² 表）：

| 编码器 | 码率 | 比熵多 | roundtrip | 解码复杂度 |
|---|---:|---:|---|---|
| 静态 rANS | **3.0178** bit | +0.0001 | ✅ | 9 op/符号 |
| canonical Huffman | 3.0922 bit | +0.0558 | ✅ | 3 op/符号 |
| 定长 4 bit | 4.0000 | — | — | 1 op |

距 R(D) 界：实测 `D/σ²=0.02029`，界 `0.5·log2(1/D)=2.8117`，我们 3.0177 → **差 +0.206 bit（7.3%）= 标量量化的 1.53 dB 格填充损失**。

> 标量量化 + 熵编码这条路**已经走到头**；再往下只有矢量量化能拿回那 7%。

## 3. 码率训练：CBR 把 bpw 变成目标值

λ 是不稳定旋钮：

| 量化器学习率 qlr | 结果 |
|---:|---|
| 0.1 | 5/5 停在 4-bit 档（2.25 bits / 2.04 bpc） |
| 1.0 | **双稳态**：1.878/1.851 与 3.175/1.834 各半 |
| 3.0 | **3/3 压死**：step 爆到 1.23，99.99% 归零，bpc=8.0 |

换成**投影控制**（每 20 步测抽样码流熵，调全局 log-step 增益命中目标）：

| 目标 bpw | 实测（2 seed） | 跨 seed 差 |
|---:|---:|---:|
| 3.0 | 3.254 / 3.254 | 0.000 |
| 2.5 | 2.649 / 2.649 | 0.0004 |
| 2.0 | 2.081 / 2.081 | 0.0001 |
| 1.5 | 1.525 / 1.526 | 0.001 |
| 1.2 | 1.202 / 1.201 | 0.001 |
| 1.0 | 1.005 / 0.998 | 0.007 |

**码率可复现到 ±0.001 bit，双稳态消失，λ 可以不要。**

## 4. 死区（dead zone）：低码率的通行证，不是普适增益

CBR 固定码率后，唯一变量是 dz：

| 目标 bpw | dz=1 | dz=1.5 | dz=2.0 | 死区值多少码率 |
|---:|---:|---:|---:|---:|
| 2.0 | 1.824 | — | — | ≈0 |
| 1.5 | 1.931 | **1.910** | 1.914 | 0.14 bit（9%） |
| 1.2 | 1.980 | **1.939** | 1.942 | 0.27 bit（22%） |
| 1.0 | 2.014 | 2.022 | **1.980** | 0.20 bit（20%） |

解析对照（标准正态源，`ecsq_theory.py`）：

```
H=2.5 → dz*=1.00    H=1.6 → dz*=1.00    H=1.3 → dz*=1.10
H=1.0 → dz*=1.50（+0.17 dB）   H=0.8 → dz*=1.75（+3.44 dB）
H=0.6 → dz*=2.00    H=0.45 → dz*=2.50
```

机制：字母表固定 15 符号时，**码率和动态范围绑死**。dz=1 想降码率只能加大 step，
而 step 一大外部电平就吞尾部 → 饱和 → 失真爆炸。死区把"降码率"的代价从"饱和"改成"中心 bin 变宽"。

```powershell
python labs\ecsq_theory.py
python labs\dz_train.py --steps 1500 --mode wd --qat 1 --clipste 1 --cbr 1.2 --dzfix 1.5 --tag dz15 --seed 0
```

## 5. 后验降档不可行，"训一次多档"不成立

嵌套字母表剪枝（重建值一个都不改，只合并最外码）：

| 模型 | 15 符号 | 7 符号 | 3 符号（三元） |
|---|---:|---:|---:|
| **4-bit QAT** | 3.353 / **1.876** | 2.025 / 5.427 | 1.214 / **7.393** |
| rate 三元解 | 1.362 / 1.905 | 1.362 / 1.905 | 1.269 / 2.044 |

4-bit 剪到三元：bits −64%，但质量从 1.88 崩到 **7.39 bpc（+5.5）**。
而在 1.2 bits 下**重新训练**只花 +0.06 bpc。
→ **在目标码率下训练的价值 = 5.3 bpc。**

另一个陷阱：`step` 是**尺度**不是档位旋钮。训练时 dz 从 1.0 挪到 1.049（2.4% 增益误差），
bpc 从 1.905 掉到 2.111 —— **一个 reconstructed scale 的 2.4% 误差值 0.2 bpc**。

```powershell
python labs\dz_prune.py rate_dz1_0.01_s0 wdq_s0
```

## 6. 真模型：Qwen3-1.7B 全流程

反量化 OpenVINO IR → torch Qwen3（RMSNorm/RoPE/GQA/qk-norm/SwiGLU，311/311 张量）：

```
ppl = 18.466（581 tokens）
```

踩坑记录（都在 `real_qwen.py` 注释里）：i4 是二进制补码、`scale` 可以为负（符号烘进权重）、
`json.load` 必须显式 utf-8（否则词表键全乱）、RoPE 的 cos/sin 要 cast 到 x.dtype、
1.7B 是 tied embedding（没有 `self.lm_head.weight`）。

### 6.1 PTQ 悬崖

用 IR 原始 per-row scale 对齐（`step = κ·|scale|`，**κ=1 是精确恒等**）：

| κ | 有效电平 | bpw | 体积（仅 Linear） | ppl |
|---:|---:|---:|---:|---:|
| **1.0** | 17 | 3.064 | 0.540 GB | **18.47**（恒等 ✓） |
| 1.5 | 11 | 2.441 | 0.430 GB | 39.61 |
| 2.0 | 9 | 2.229 | 0.393 GB | 263889 |
| 2.5 | 7 | 1.743 | 0.307 GB | 1.2e6 |
| 4.0 | 5 | 1.471 | 0.259 GB | 9.1e7 |
| 8.0 | 3 | 0.508 | 0.091 GB | 8.4e8 |

**部署网格是个悬崖**：3.06 → 2.44 bpw 就 +114% ppl。
（第一版用 `step = s·σ_row` 重建网格，那是把权重挪到另一个网格，测的是错位，ppl 一律 1e5。）

### 6.2 逐层敏感性是平的，但损伤按层连乘

s=1.2（≈1.8 bpw）单独量化每一层：ppl 17.5–20.6，全部 ±10%，**没有一个脆弱的层**。
28 层一起压：**ppl = 511.8（+2672%）**。

> 不是"某些层碰不得"，是**每层都差不多、误差按层连乘**。
> 逐层分配没有着力点，与第 1 节的 i.i.d. 结论互为佐证。

### 6.3 词表侧：无损到底，有损可行

只量化 embedding（head 同步），基线 ppl 18.47：

| bits | 码流熵 | 体积 | ppl | Δ |
|---:|---:|---:|---:|---:|
| 8 | 7.169 | 278.9 MB | 18.40 | −0.3% |
| **6** | **5.136** | **199.8 MB** | **18.36** | **−0.6%** |
| 5 | 4.092 | 159.1 MB | 19.08 | +3.3% |
| 4 | 3.005 | 116.9 MB | 19.58 | +6.0% |
| 3 | 1.850 | 71.9 MB | 26.87 | +45% |
| 2 | 0.434 | 16.9 MB | 32123 | 死 |

无损手段（零点、行内差分、每行一张表、低秩主子空间）最多省 **1.3%** —— 这块不该熵编码，该降精度。

### 6.4 QAT：8/28 层 + 600 步只恢复 0.24%

```
fp16 18.466 → κ=1.5 量化 39.539 → QAT 600 步 39.445（恢复 0.24%）
```

因为损伤按层连乘，只训 8 层等于只修 8 个因子；600 步 × 6 KB 语料也不够 403M 参数适配。

```powershell
python labs\real_qwen.py check; python labs\real_qwen.py ppl
python labs\real_quant_curve.py; python labs\real_sensitivity.py; python labs\real_vocab.py
python labs\qat_real.py --kappa 1.5 --train_layers 8 --steps 600
```

## 8. 这些结论的边界

1. **不是 SOTA**。压缩比与 ISCA'26 的 tile-rANS 打平（都贴着熵界），但**没有 GEMM 融合解压**；
   2 bpw 以下无解（没做 VQ）；toy 上的三元坍塌不可外推到 LLM。
2. **PTQ 只能在 FP16 原件上做**。在已量化的 INT4 产物上再量化是伪命题。
3. **1.33M 参数的训练结论**（三元坍塌 +0.04 bpc、死区收益 9–22%）只在 5M 上部分复现，
   8B 规模未验证。
